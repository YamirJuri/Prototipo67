# Planes de estudio

Copiar los PDFs aprobados aquí. Completar `planFile`, título, duración, modalidad y `years` de cada carrera en `01-configuracion.js`. Los datos null muestran "pendiente de publicación". El JSON es una guía editorial; no se importa automáticamente.

Revisar el renderizador de materias en `03-paginas.js` antes de cargar el plan: cada año utiliza `{ title, subjects: [{ name, regime, hours }] }`. No usar estas claves como fuente normativa: cotejar con resolución vigente y confirmar la forma exacta contra el renderizador.
