# Calendario académico

Cargar sólo fechas aprobadas en `config.academicEvents`, consultando la estructura de `calendar()` en `03-paginas.js`. El JSON está vacío a propósito y no se carga automáticamente. Colocar el calendario oficial PDF aquí y asignar `calendarFile`. Mientras no exista, la interfaz distingue el calendario mensual de las fechas institucionales pendientes. No confundir el mes actual con un período abierto de inscripción.
